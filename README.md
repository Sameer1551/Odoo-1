# Traveloop Dashboard

A modern, comprehensive dashboard for planning and managing your trips, built with Next.js, Tailwind CSS, and Shadcn UI.

## Features

- **Trip Overview**: View and manage all your upcoming trips.
- **Budget Tracking**: Monitor your travel expenses seamlessly.
- **Smart Itinerary**: Organize your day-to-day travel plans.
- **Packing Checklist**: Never forget an essential item again.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
